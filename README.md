# Arx Fatalis VR — development snapshot v60

Закрытая резервная копия разработки автономного 6DoF VR-порта Arx Fatalis для PICO / Android arm64. Это **незавершённый прототип**, а не стабильный релиз. Снимок сохранён 23 сентября 2026 года по просьбе владельца проекта вместе с игровыми ресурсами.

## Что сохранено

- `ArxAndroid/` — изменённый движок Arx Libertatis, Android VR bridge, взаимодействие, камера, стереорендер и UI.
- `PICO-OpenXR-Demos/` — изменённый OpenXR host, контроллеры и модели рук, композиция меню, диагностический ввод.
- `ArxVR-Android/` — Android приложение и конфигурация сборки.
- `ArxWindows/` — ранняя Windows/OpenXR ветка, включая рабочее дерево вложенного движка.
- `tools/` — сборка, упаковка, тесты, анализ видео; существующие скрипты сохранены как есть.
- `third_party/`, `thirdparty/` — исследовательские/SDK исходники, имеющиеся в рабочем каталоге.
- `diagnostics/` — текстовые отчёты, включая ограничения автоматических проверок.
- `backup/` — происхождение upstream, пофайловый SHA-256 манифест полного архива, исключения и инструкция восстановления.

**Полный набор данных находится в [закрытом GitHub Release](https://github.com/ARST113/ArxFatalis-VR/releases/tag/snapshot-2026-09-23-v60).** Многотомный архив содержит рабочие ресурсы, русификаторы, HD-текстуры, предыдущие APK, исходники зависимостей, результаты сборки, локальный инструментальный набор, скриншоты, видео и журналы. Отдельно включены оригинальная папка Steam-игры, ранние материалы этой задачи и файловый каталог Arx VR с подключённого PICO (игровые данные и сохранения). Другие приложения и данные устройства не копировались.

Пароли, ключи подписи, Git credentials, Android debug keystore, VCS metadata и Gradle caches не включены. Истории чужих репозиториев не импортированы; их исходные commit SHA указаны в `backup/upstream-provenance.json`. Исходные локальные рабочие деревья не переименовывались, не сбрасывались и не коммитились.

## Последняя установленная сборка

`app-debug-v60-handspace-fullbuild.apk`

SHA-256: `0d5b82c68cc14672bc86d5bc3ebb447566e148ded02b095af85c5d85256b3c59`.

v60 исправляет пропущенное преобразование локальных координат модели кистей и использует актуальную центральную позу головы для начального положения меню. Меню остаётся неподвижным после открытия; возврат фокуса переустанавливает его опору.

**v59 (`app-debug-v59-handspace-menu.apk`) — известная неудачная промежуточная сборка с чёрным экраном. Не устанавливать.** Она сохранена только как часть истории артефактов. После изменения виртуального интерфейса необходима полная пересборка OpenXR host, а не только затронутых `.cpp`.

## Статус проверок

При подготовке этого снимка заново выполнены 8 случаев преобразования кистей, 7 проверок положения меню и текстовая проверка подключения обработки смены reference space. Они прошли. Полная сборка и игровой прогон в этом сеансе публикации не выполнялись.

Предыдущий прогон v60 на PICO включал видимое изображение обоих глаз, вход в тюремную сцену, синтетические движения рук, сжатие пальцев, короткие шаги вперёд/назад и открытие раздела загрузки/сохранения. Это не физическое движение контроллерами и не прохождение уровня.

**Не подтверждены:** эргономическое совпадение настоящих рук, корректное удержание кости/черепа/стула, индивидуальный обхват пальцами, бой предметами, броски, физический присед, полное прохождение и стабильные 47–58/75 FPS. Старые автоматические проверки могли давать ложноположительные результаты — см. [аудит](diagnostics/human-agent-v57/verification-audit.md).

Подробности: [отчёт v60](diagnostics/hand-space-v59/report-v60.md), [восстановление и сборка](backup/RESTORE.md).
